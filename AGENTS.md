* GSAP

* @nuxt/image
* @nuxtjs/seo
* Vue Router

## Rules

1. **Do not change the tech stack without explicit permission.**
2. **Do not add, remove, or replace dependencies without explicit permission.**
3. **Do not change the project architecture without explicit permission.**
4. **Do not modify existing configuration without a clear reason.**
5. **Do not modify or delete existing features unless explicitly requested.**
6. **Every completed feature or meaningful change must be committed to Git.**
7. **Keep commits focused on one feature or change.**
8. **Do not modify unrelated files.**
9. **Do not use `any`, `@ts-ignore`, or similar workarounds to hide errors.**
10. **Run the relevant checks/build before considering a feature complete.**
11. **If a change requires breaking an existing rule, stop and ask for permission first.**

## Git Commit Format

Use conventional commit messages:

```text
feat: add project section
fix: fix mobile navbar
style: improve hero section
refactor: extract project card
chore: update configuration
```

## Important

When unsure whether a change is allowed, **ask for permission before making the change**.
